# Application Branding Assets (`assets/`)

This directory contains the visual branding assets, icons, and UI preview media bundled with **Universal Disk Health Monitor**.

---

## Asset Catalog

| Asset | Format / Dimensions | Description |
| :--- | :--- | :--- |
| [`AppIcon.png`](AppIcon.png) | 1024×1024 RGBA PNG | Master high-resolution application icon generated by [`scripts/generate_app_icon.swift`](../scripts/generate_app_icon.swift) |
| [`AppIcon.icns`](AppIcon.icns) | Multi-resolution `.icns` | Complete Apple Icon Image (`16×16` through `512×512@2x`) embedded in `DiskHealthMonitor.app/Contents/Resources/` |
| [`MainWindow.png`](MainWindow.png) | 777×1366 RGBA PNG | High-resolution capture of the menu bar dashboard view displayed in [`README.md`](../README.md) |

---

## Regenerating Icons

To rebuild the icon assets from source:

```bash
rm -f assets/AppIcon.png assets/AppIcon.icns
./build_and_install.sh
```
